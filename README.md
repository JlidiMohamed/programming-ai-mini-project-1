# Applied Programming for AI - Mini-project 1: Service Ticket Data Pipeline

**Author:** Mohamed Jlidi - Student number: a22601339

## Dependencies
Python 3.10+, `numpy`, `pandas`, `jupyter` (`pip install numpy pandas jupyter`).

## How to run (fresh clone)
1. Keep the unchanged `service_tickets.csv` in the repository root.
2. Open `project_1_student.ipynb` (Jupyter or Google Colab) and run Runtime > Restart and run all.
3. Results are written to `outputs/`: `clean_tickets.csv`, `rejected_tickets.csv`, `ticket_features.csv`, `audit.json`. `REPORT.md` is generated in the root.
